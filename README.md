
# Agro e Vida

## Descrição

**Agro e Vida** é um projeto de site responsivo desenvolvido com **HTML**, **CSS
** e **JavaScript puro (Vanilla JS)**.

O objetivo é apresentar informações sobre agricultura, sustentabilidade, inovação tecnológica no campo e qualidade de vida rural por meio de uma interface moderna, acessível e intuitiva.

O projeto foi construído sem o uso de frameworks ou bibliotecas externas, garantindo simplicidade, desempenho e fácil manutenção.

## Funcionalidades

### Cabeçalho Responsivo

* Logo do projeto "Agro e Vida"
* Menu de navegação
* Menu mobile para telas menores

### Banner Principal

* Imagem de fundo temática
* Texto de apresentação
* Botão de navegação para a seção principal

### Seção Agricultura

* Importância da agricultura
* Três cartões informativos

### Seção Sustentabilidade

* Práticas sustentáveis no campo
* Ícones utilizando emojis

### Seção Tecnologia

Apresenta tecnologias modernas utilizadas no agronegócio:

* Drones
* Irrigação Inteligente
* Monitoramento de Culturas

### Galeria

* Grade responsiva de imagens relacionadas ao meio rural

### Formulário de Contato

Campos:

* Nome
* E-mail
* Mensagem

Validações em JavaScript:

* Nome com mínimo de caracteres
* E-mail válido
* Mensagem obrigatória

### Botão Voltar ao Topo

* Exibido após a rolagem da página
* Retorna suavemente ao início

### Rodapé

* Informações do projeto
* Ano atualizado automaticamente pelo JavaScript

## Recursos de JavaScript

### Menu Mobile

Permite abrir e fechar a navegação em dispositivos móveis.

### Rolagem Suave

Navegação agradável entre as seções da página.

### Animações ao Rolar

Elementos aparecem gradualmente conforme entram na área visível da tela.

### Validação de Formulário

Verifica os dados antes do envio.

### Atualização Automática do Ano

O ano exibido no rodapé é atualizado automaticamente.

## Como Executar

1. Baixe os arquivos do projeto.
2. Coloque os arquivos na mesma pasta:

   * index.html
   * style.css
   * script.js
3. Abra o arquivo `index.html` em qualquer navegador moderno.

Nenhuma instalação adicional é necessária.
